# MyCloud — Облачное хранилище файлов

Android-приложение для хранения и управления файлами.

## Возможности
- 📂 Загрузка файлов из памяти устройства
- 📋 Просмотр списка файлов
- 🔍 Детальная информация о файле
- ✏️ Редактирование данных файла
- 🗑️ Удаление файлов

## Технологии
- **Kotlin**
- **Jetpack Compose** — современный UI
- **Room** — локальная база данных
- **MVVM** — архитектурный паттерн
- **Coroutines + Flow** — асинхронность
- **Navigation Compose** — навигация между экранами

## Экраны
1. **Список файлов** — главный экран
2. **Детали файла** — подробная информация
3. **О приложении** — информация о приложении

## Состояния экрана
- Loading — загрузка данных
- Success — успешное отображение
- Error — обработка ошибок
